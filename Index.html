선택

• 조합 예: 2부 + 전체 + 전체=2부 전체, 1부 + 드림 + 전체=1부 드림반 전체, 2부 + 우리 + 우3=2부 우리반 3반만

결과

부서: - / 학년: - / 반: -
인원: 0명
부서를 선택하면 반 목록이 자동으로 채워집니다. 반 선택 후 조회 버튼을 누르세요.
• 원본 시트(N부 예꼬 주소록)의 모든 열을 그대로 카드 형태로 출력합니다(열을 추리지 않음).
• 이 시트는 원본이므로 이 도구는 읽기 전용입니다 — 시트에 값을 쓰지 않습니다.
• 반 목록은 시트에서 실제 존재하는 값만 자동으로 뽑아 보여줍니다(연도별로 반이 바뀌어도 코드 수정 불필요).
• 카드형이라 열이 많아도 가로 스크롤 없이 모바일에서도 확인할 수 있습니다.
• 🔒 이 화면은 원본 시트 주소를 전혀 알지 못합니다 — 조회는 서버(Apps Script) 안에서만 이뤄집니다.

👩‍🏫 교사용: 반 업데이트 업로드

• 위에서 엑셀(.xlsx) 다운로드로 우리 반 파일을 받아서 뒷부분(특별사항 등)만 수정한 뒤, 여기서 다시 올려주세요.
• 이름·반·학년 같은 열은 잠겨있어 실수로 못 바꿉니다 — 수정 가능한 열만 편집됩니다.
• 같은 반을 다시 올리면 이전 내용을 덮어씁니다(중복 안 쌓임). 다른 반 파일을 올리면 자동으로 거부됩니다.
