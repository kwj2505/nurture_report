# 🌱 유치부 양육보고서 추출 (GAS 보안 버전)

## 왜 GitHub Pages가 아니라 Google Apps Script인가
기존 방식(정적 `index.html`을 GitHub Pages로 배포)은 소스 코드 안에 구글 시트 주소가 그대로 들어있어서,
**공개 저장소를 열어본 사람이 그 주소를 따라가면 예꼬들의 이름·생년월일·연락처·주소가 그대로 보이는 문제**가 있었다.

이 폴더의 `Code.gs` + `Index.html`은 그 문제를 없앤 버전이다.
- 실제 시트 조회는 전부 **서버(Apps Script)** 안에서 일어난다.
- 브라우저(클라이언트) 쪽 소스 어디에도 시트 주소가 없다 — `Code.gs`도 마찬가지(주소는 코드가 아니라 "스크립트 속성"에 저장).
- 그래서 이 두 파일은 **GitHub에 Public(공개) 저장소로 올려도 안전**하다.

## 배포 방법 (최초 1회)

### 1단계: Apps Script 프로젝트 만들기
1. drive.google.com 접속 → **새로 만들기 → 더보기 → Google Apps Script**
2. 프로젝트 이름을 "유치부 양육보고서 추출" 등으로 변경

### 2단계: 코드 붙여넣기
1. 기본 `Code.gs`의 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣기
2. 왼쪽 메뉴 `+` → **HTML** → 파일 이름을 정확히 `Index` (대문자 I)로 생성
3. 생성된 `Index.html`에 이 폴더의 `Index.html` 내용을 그대로 붙여넣기
4. `Ctrl+S`로 저장

### 3단계: 시트 주소 등록 (여기가 핵심 — 코드에 절대 직접 적지 않는다)
1. 왼쪽 톱니바퀴 아이콘 **"프로젝트 설정"** 클릭
2. 맨 아래 **"스크립트 속성"** 섹션 → **"스크립트 속성 추가"**
3. 아래 2개를 추가:

   | 속성(키) | 값 |
   | :--- | :--- |
   | `SHEET1_LINK` | 1부 예꼬 주소록 시트 링크 (`https://docs.google.com/spreadsheets/d/.../edit?gid=...`) |
   | `SHEET2_LINK` | 2부 예꼬 주소록 시트 링크 |

4. 저장

### 4단계: 권한 승인 + 점검
1. 함수 선택 박스에서 `checkSetup`을 선택하고 ▶ 실행
2. "승인 필요" 창이 뜨면: 권한 검토 → 본인 계정 선택 → 고급 → 이동(안전하지 않음) → 허용
3. 하단 "실행 로그"에 두 속성 모두 `✅ ... 설정됨, 시트 열기 성공`이 뜨면 준비 완료

### 5단계: 웹 앱으로 배포
1. 오른쪽 위 파란 **"배포" → "새 배포"**
2. 유형(톱니바퀴) → **웹 앱**
3. 실행 주체: **나(Me)** / 액세스 권한: 필요에 맞게(예: 모든 Google 계정 사용자)
4. **배포** 클릭 → 생성된 URL(`https://script.google.com/macros/s/.../exec`)이 실제 서비스 주소

### 6단계: 구글 사이트 도구 버튼에 연결
기존 "양육보고서 추출(개발중)" 버튼의 링크를 5단계에서 만든 URL로 교체하면 끝.

## 매년(예: 12월) 시트 주소가 바뀔 때 — 코드 수정 없이 딱 여기만

1. Apps Script 편집기 → 왼쪽 톱니바퀴 **"프로젝트 설정"**
2. **"스크립트 속성"**에서 `SHEET1_LINK` / `SHEET2_LINK` 값을 새 주소로 수정 → 저장
3. **끝.** 코드 수정도, 재배포도 필요 없다 — 다음 요청부터 바로 새 주소로 조회된다.

## 파일 구성
- `Code.gs` — 서버: 시트 조회(읽기 전용), 스크립트 속성에서 주소 로딩, `doGet`으로 화면 서빙
- `Index.html` — 클라이언트: 부서/학년/반 선택 UI, 카드형 결과, 텍스트복사/엑셀다운로드/이미지저장 (디자인은 01~04번 도구와 동일)
- 원본 시트 쓰기 코드는 어디에도 없음 — 완전 읽기 전용
